Problem

현행 문제점

QR이나 시리얼 코드만으로는
위조·복제를 완벽히 막을 수 없습니다.

Point 1

위조 위험 증가

SNS, 중고시장 등에서 비공식 굿즈가 확산

Point 2

QR 인증의 한계

이미지 복제만으로 인증된 것처럼 위장 가능

Point 3

브랜드 신뢰 하락

소비자는 정품 여부를 구분하기 어려움

Service

솔루션

스테가비전은 AI 기반 Invisible 워터마크 기술로,
이미지 자체를 정품 인증 라벨로 만듭니다.

Point 1

AI 기반 숨은 워터마크 삽입

포토카드 이미지 속 눈에 보이지 않는 신호를 삽입하여, 육안으로는 정보를 식별할 수 없지만 심미성이 중요한 굿즈에도 완벽히 적용할 수 있습니다.

Point 2

다단계 검증 프로세스

앱 촬영 시 숨은 코드를 복원하여 오프라인 1차 판정을 하고, 서버 이력과 대조하여 최종 확정합니다.

Point 3

소유권 관리 및 이력 추적

중앙 DB 공유 방식으로 최초 구매자만 최초 등록이 가능하며, 중고 거래 시 소유권 이전기록도 서버에 투명하게 반영됩니다.

Service

스테가비전 출시 어플 '히든'

StegaVision의 핵심 기술이 적용된 AI 기반 Invisible Steganography 인증 어플로,
히든 데이터를 카메라로 즉시 확인할 수 있는 모바일 앱입니다

데이터 삽입된 이미지 생성

  • 가시적인 코드 없이 원본과 유사한 이미지 생성
  • 시각적 왜곡 없이 데이터 삽입 가능
  • 오프라인 환경에서도 삽입된 데이터 복원 가능
  • QR코드 대비 비가시적, 심미적 장점 보유

이미지로부터 실시간 데이터 검출

  • 오프라인 환경에서 그 속에 삽입된 데이터를 완벽히 복원
  • 이미지•영상으로부터 즉시 데이터 인식 및 추출 가능
  • 카메라 촬영 환경(각도, 조명, 노이즈)에서도 강인한 검출 성능
  • 실시간 처리 속도로 다양한 응용 서비스 적용 가능
